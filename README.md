# HOW
HOW Loader (Homebrew Operating-system Wrapper) is a homebrew project exploring ways to run Steam in a containerized environment on supported homebrewed consoles.

AI tools are used as a development aid to speed up debugging and help write code when I get stuck. The project is developed and tested across different systems, so branches and releases may include system-specific versions as well as experimental test builds. Check the relevant branch or release notes for details.
